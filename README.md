# PyRPA - 基于图像识别的流程自动化工具

PyRPA 是一款纯 Python 编写的轻量级 RPA(Robotic Process Automation,机器人流程自动化)工具.通过图像识别定位屏幕元素,自动执行鼠标点击、键盘输入等一系列操作,实现重复性任务的自动化.

## 功能特性

- **图像识别驱动**:截取屏幕目标区域图片,运行时自动在屏幕上匹配并定位,匹配成功后执行预设操作
- **丰富的操作指令**:支持鼠标点击/拖拽、键盘输入、热键模拟、滚动、系统命令调用、截屏、弹窗提示等 20+ 种指令
- **数据驱动执行**:通过 CSV 数据文件驱动流程,使用 `$1`/`$2` 占位符实现同一流程对不同数据的批量处理
- **可视化编辑器**:内置任务编辑器与截图工具,无需手动编辑配置文件
- **亮色/暗色主题**:支持一键切换界面主题
- **可配置热键**:通过自定义热键控制任务的开始与停止
- **超时与跳转机制**:支持找图超时处理(弹窗提示、跳过、退出、跳转到指定步骤),可实现步骤间的循环跳转

## 环境要求

- Windows 操作系统
- Python 3.11 及以上

## 依赖安装

本项目使用 `pyproject.toml` 管理依赖,推荐使用 [uv](https://docs.astral.sh/uv/) 创建虚拟环境并安装依赖.

### 使用 uv(推荐)

```powershell
uv sync
```

该命令会读取 `pyproject.toml`,自动创建 `.venv` 虚拟环境并安装全部依赖.

### 使用 pip

```powershell
python -m venv .venv
```

```powershell
.venv\Scripts\activate
```

```powershell
pip install -e .
```

## 快速开始

```powershell
python main.py
```

也可通过 uv 直接运行

```powershell
uv run main.py
```

安装后可直接使用命令启动(等价于 `python main.py`)

```powershell
pyrpa
```

## 打包为独立 exe

项目已内置 PyInstaller 打包配置(`pyrpa.spec`)与一键脚本(`build.bat`),可打成分发用的独立目录版。

### 一键打包

直接双击或在终端运行:

```powershell
.\build.bat
```

脚本会自动:安装/升级 PyInstaller → 清理旧产物 → 按 `pyrpa.spec` 打包 → 把默认 `rpa_data`(配置/示例任务)复制到输出目录。产物在:

```
dist\pyrpa\pyrpa.exe
```

### 手动打包

```powershell
uv pip install --python .venv\Scripts\python.exe "pyinstaller>=6.0"
.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean pyrpa.spec
```

### 打包说明

- **OneDir 目录模式**(相对单文件,启动更快、对带主题图片的 tkinter 应用更稳定)
- 只读资源(`sun-valley.tcl`、`theme/`)内嵌于 `_internal`,运行时从解压目录读取
- **可写数据目录 `rpa_data`**(配置/日志/截图/任务)放在 exe 同目录,随程序运行生成/保存,不内嵌
- 分发时直接把整个 `dist\pyrpa` 文件夹拷贝给使用者即可

启动后将显示主界面,基本操作流程:

1. 在顶部「工作数据」输入框中输入任务名称(默认 `task1`),按回车确认
2. 在操作项表格中配置自动化步骤(或点击「导入」加载已有配置)
3. 设置循环次数、开始热键(默认 `ctrl+1`)、停止热键(默认 `ctrl+2`)
4. 点击「保存」后,按下开始热键或点击「开始」按钮执行任务

## 操作指令说明

操作指令在表格的「执行动作」列中以 `指令=参数` 的格式填写,多个动作用中文逗号 `,` 连接.

### 鼠标操作

| 指令 | 参数格式 | 说明 | 示例 |
|------|---------|------|------|
| `左键` | X | 左键点击 X 次 | `左键=1` |
| `右键` | X | 右键点击 X 次 | `右键=1` |
| `中键` | 1 | 鼠标中键按下 | `中键=1` |
| `偏移` | x/y | 鼠标相对位移(+X 向右,+Y 向下) | `偏移=10/0` |
| `移动` | x/y | 鼠标移动到屏幕绝对位置 | `移动=500/300` |
| `鼠标拖拽` | x/y | 左键按下并拖拽到绝对位置 | `鼠标拖拽=800/600` |
| `相对拖拽` | x/y | 从当前位置相对拖拽 | `相对拖拽=10/0` |
| `左键按下` | 1 | 按下鼠标左键(与释放配套使用) | `左键按下=1` |
| `左键释放` | 1 | 释放鼠标左键 | `左键释放=1` |
| `右键按下` | 1 | 按下鼠标右键(与释放配套使用) | `右键按下=1` |
| `右键释放` | 1 | 释放鼠标右键 | `右键释放=1` |

### 键盘操作

| 指令 | 参数格式 | 说明 | 示例 |
|------|---------|------|------|
| `按键` | key | 模拟单个按键 | `按键=enter` |
| `输入` | text | 通过剪贴板粘贴输入文本 | `输入=hello` |
| `热键` | k1+k2[+k3] | 模拟组合热键 | `热键=ctrl+alt+q` |

### 其他操作

| 指令 | 参数格式 | 说明 | 示例 |
|------|---------|------|------|
| `等待` | 秒数 | 延时等待 | `等待=2` |
| `滚动` | 像素值 | 正数向上 / 负数向下滚动 | `滚动=-2000` |
| `命令` | cmd | 调用系统 CMD 命令 | `命令=notepad` |
| `截屏` | 1 | 全屏截图,保存到 Screenshot 目录 | `截屏=1` |
| `弹窗` | text | 弹窗提示(可用于暂停检查) | `弹窗=hello` |
| `跳转` | 步骤序号 | 跳转到指定步骤(可实现循环) | `跳转=3` |

## 步骤参数说明

每个自动化步骤包含以下参数:

| 参数 | 说明 |
|------|------|
| **A 备注** | 步骤备注,不影响运行 |
| **B 启用** | `1` 为启用,`0` 为禁用(跳过该步骤) |
| **C 图片名** | 找图模式:填写截图文件名(`.png`)；留空则直接执行动作(非找图模式) |
| **D 超时时间** | 等待图片出现的最大时间(秒).`0` = 只找一次；`-1` = 一直等待直到找到 |
| **E 超时行为** | 图片超时未找到时的处理方式:弹窗 / 跳过 / 退出 / 跳转到序号 |
| **F 找图间隔** | 超时时间内,两次找图之间的时间间隔(秒) |

## 数据驱动模式

当工作数据目录下存在 `data.csv` 文件时,程序会进入数据驱动模式:

- CSV 文件第一行为表头(自动跳过),从第二行开始为数据
- 每行数据执行一遍完整流程,步骤动作中的 `$1`、`$2` 等占位符会被替换为对应列的值
- 也可通过主界面的「数据CSV」按钮选择其他 CSV 文件

**示例**:步骤动作 `输入=$1,等待=1,左键=1`,数据行 `张三,100`,则实际执行 `输入=张三,等待=1,左键=1`

## 配置文件说明

`PyRPA.ini` 保存程序的持久化配置:

| 字段 | 说明 |
|------|------|
| `[SAVE] optionselect` | 上次使用的工作数据名称 |
| `[SAVE] loopcounter` | 循环次数 |
| `[SAVE] starthotkey` | 开始热键 |
| `[SAVE] stophotkey` | 停止热键 |
| `[SAVE] logmethod` | 日志方式:0=不记录,1=写文件,2=控制台 |
| `[SAVE] theme` | 主题:0=亮色,1=暗色 |
| `[TASKCFG] autoruntaskdir` | 自动运行的任务目录名(配合 Windows 计划任务实现定时运行) |

## 目录结构

```
PyRPA/
├── main.py              # 主程序(界面、执行引擎)
├── gui_editor.py        # 截图工具与任务编辑器
├── PyRPA.ini            # 配置文件
├── sun-valley.tcl       # Sun Valley 主题入口
├── theme/               # 亮色/暗色主题资源
└── rpa_data/            # 工作数据目录
    ├── img/             # 全局截图图片目录
    └── <任务名>/        # 各任务独立目录
        ├── task.json    # 任务步骤配置
        └── data.csv     # 运行数据(可选)
```

## 注意事项

- 截图尽可能小,可提升图像匹配速度
- 找图间隔设置适当大一些,可降低 CPU 占用(但响应会变慢)
- 任务名称、图片文件名仅允许中文、字母、数字、`_`、`-`,最长 10 个字符
- 默认使用 `pyautogui.FAILSAFE = True` 保护,将鼠标快速移到屏幕左上角可中断失控的自动化
